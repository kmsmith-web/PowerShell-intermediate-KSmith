<#
Displays the user's name.

.DESCRIPTION
The Get-NameInfo function displays the name Kimberly Smith in the
PowerShell console. This function is used to demonstrate creating
and running a simple custom PowerShell function.

.NOTES
Author: Kimberly Smith
Date: 11/16/2026

.EXAMPLE
Get-NameInfo

Output:
Kimberly Smith
#>

function Get-NameInfo {
    Write-Output "Kimberly Smith"
}


function Get-NameInfo {
    Write-Output "Kimberly Smith"
}

Get-NameInfo
